⚖️
Dónde está realmente el límite

En razonamiento puro, la frontera sigue ganando; por eso existe el modo Connected. Pero la ventaja de lo local no es el CI: es costo cero por token, cero salida de datos y sin límites de solicitudes. Route by task, not by loyalty.

06 · The two traps

Por qué la gente cree que lo local es malo.

It's usually not the model. It's one of these two settings.

🧠
El valor predeterminado de 4,096 tokens

Qwen3-Coder's real context is 256K. Ollama ships it capped at 4K — you're using ~1.6% of the brain, then blaming the model.

native · 256Kpredeterminado · 4K
Corrección: OLLAMA_CONTEXT_LENGTH=65536 ollama serve
🌊
El límite de la caché KV

El contexto consume memoria: un 70B necesita ~42GB solo para la caché a 128K. Consumer machines top out around 32–64K usable — the cache won't fit, not the model.

Corrección: Cuantización de la caché KV — q8_0 reduce casi a la mitad la memoria de la caché, con una pérdida mínima de calidad.
07 · Wire it up

Tres comandos para una sala cerrada.

Ollama exposes an OpenAI-compatible endpoint on localhost:11434 — Hermes se integra como cualquier otro cerebro. Nada sale del equipo.

terminal · local y gratis
# 1 · pull the coder
$ ollama pull qwen3-coder:30b-a3b

# 2 · raise the context BEFORE you judge it
$ OLLAMA_CONTEXT_LENGTH=65536 ollama serve

# 3 · point Hermes at localhost
$ hermes config set model qwen3-coder:30b-a3b --base-url http://localhost:11434/v1
